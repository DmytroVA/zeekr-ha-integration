# Каталог команд застосунку Zeekr

Усі ідентифікатори віддалених команд (`serviceId`), знайдені в SDK застосунку Zeekr 5.0.8
(пакет `com.geely.snc`, звірка 2026-11-15), і що з кожним робить інтеграція.

SDK спільний для всіх моделей Geely / Zeekr / Lynk & Co, тому значна частина команд до
Zeekr 001 не стосується. Наявність ідентифікатора в застосунку не означає, що авто його
приймає: «перевірено» тут лише те, що позначено ✅.

**Статуси:** ✅ реалізовано · 📋 у планах (номер завдання з [BACKLOG.md](BACKLOG.md)) ·
⛔ не робимо (з причиною) · ❔ не досліджено.

Формат команди: `{serviceId, command, setting: {serviceParameters: [{key, value}], operationScheduling: {duration}}}`
на `/ms-remote-control/.../remoteControl/control`. Будь-яку з них можна надіслати вручну
сервісом `zeekr.remote_control`.

Описи взято з назв методів і службових підписів у коді застосунку. Де призначення
виведене лише з назви, це позначено «ймовірно».

## Клімат і комфорт

| serviceId | Що робить | Параметри | Статус |
|---|---|---|---|
| `ZAF` | Клімат нового покоління: кондиціонер, швидкий нагрів/охолодження, обігрів скла, сидіння, кермо | `AC` + `AC.temp`, `AC.duration`; `RW` / `RC` + `.duration`; `DF` + `DF.level=2`, `DF.duration`; `SH.<місце>` / `SV.<місце>` + `.level`, `.duration`; `SW` + `SW.level`, `SW.duration`. Місця: `11` водій, `19` пасажир, `21`/`29` другий ряд, `31`/`39` третій ряд | ✅ усе, крім третього ряду (на 001 його немає) |
| `ZAF` → `CV` | Вентиляція салону через `ZAF` | `CV`, `CV.level`, `CV.duration=1` | ⛔ вентиляцію вже робить `RCC` |
| `RCC` | Вентиляція салону | `rcc.conditioner=50`, `rcc.ventilation=0`, тривалість ×6 | ✅ |
| `RCC` (інші режими) | Попереднє кондиціонування та сидіння для старішої платформи | `rcc.conditioner=1` + `rcc.temp`; `=4` + `rcc.heat`; `=3` + `rcc.ventilation` | ⛔ дублює `ZAF` |
| `RCE` | Клімат, обігрів скла, сидіння, кермо, вентиляція для старішої платформи | `rce.conditioner` (`1` клімат, `2` скло, `3` підігрів сидінь, `4` вентиляція сидінь, `50` вентиляція салону), `rce.temp`, `rce.level`, `rce.heat`, `rce.ventilation` | ⛔ дублює `ZAF` |
| `RSH` | Підігрів сидінь для платформи GEEA 1.0 | як у `RCE` | ⛔ дублює `ZAF` |
| `RFD` | Ароматизатор салону | `channel_id`, `code`, `level`, опційно `duration`; вимкнення: `channel_id=0`, `level=0` | 📋 T23 — авто його має (у статусі є `fragActive` і три картриджі) |
| `ZAM` | Очищення повітря в салоні | `start` / `stop`; варіант VOC: `zam=2` | ⛔ рішення власника: не потрібно |
| `ZAB` | Постійна температура салону | `zab.model=1`, `start` / `stop` | ⛔ рішення власника: не потрібно |
| `RPP` | Запит до авто заміряти PM2.5 і/або температуру салону | `rpp` = `pm` / `temp` / `pm-temp` | ❔ сенсори PM2.5 і температури вже є; чи дає команда свіжіші дані — не перевіряли |
| `ZBB` | Кисневий генератор | `superiorOxyActivate`, `duration` | ⛔ немає обладнання |
| `ZAE`, `PAE`, `ZAJ` | Холодильник | режим, температура | ⛔ немає обладнання |
| `PAP` | Морозильна камера | `pap`, `pap.temp` тощо | ⛔ немає обладнання |
| `PAH` | Режими заднього ряду (2 / 4 / 6 осіб, «гольф», «простір») | `pah.mode` = `1`…`5` | ⛔ для мінівенів |

## Доступ: двері, вікна, багажник

| serviceId | Що робить | Параметри | Статус |
|---|---|---|---|
| `RDU` / `RDL` | Відімкнути / замкнути двері | `command=start`, `door=all` | ✅ |
| `RDU` / `RDL` | Окремі двері | `door` = `front-left`, `front-right`, `back-left`, `back-right` | ⛔ не заплановано: вистачає центрального замка |
| `RDU` | Відімкнути багажник | `command=start`, `target=trunk` | ✅ |
| `RDL` / `RTL` | Замкнути багажник | `command=stop`, `target=trunk` | 📋 T18 |
| `RDU` / `RDL` або `RDO` / `RDC` | Лючок зарядки | `target` = `front-charge-lid` / `back-charge-lid` | 📋 T17 |
| `RDU` / `RDL` або `RDO` / `RDC` | Капот | `target=hood` | ❔ у README позначено як експериментальне, на авто не перевіряли |
| `RLU` | Капот для платформи GEEA 1.0 | `target=hood` | ⛔ інша платформа |
| `RTU` / `RTL` | Лючок бака | `target=tank-flag` | ⛔ немає бака |
| `RWS` | Вікна: відкрити, провітрювання, закрити | `start` + `target=window`; `start` + `target=ventilate`; `stop` + `target=window` | ✅ |
| `RWS` | Люк і шторка даху | `target` = `sunroof`, `sunroofVentilate`, `sunshade`, опційно `pos` | ⛔ авто повідомляє положення шторок `101` (схоже, приводу немає) |
| `RHL` | Пошук авто: світло, клаксон | `rhl` = `light-flash`, `horn-light-flash`, `horn` | ✅ перші два (не перевірені, вимкнені за замовчуванням); 📋 T20 `horn` |
| `ZAG` | Приватний замок (сейф / бокс із кодом) | `code`, `model`, `boxId` | ⛔ не потрібно для HA |
| `ZAD` | Гостьовий режим | `code`, `model`; вихід — `command=exitService` | ⛔ не потрібно для HA |
| `ZAH` | Віддалений дозвіл на запуск авто без ключа | `zah.rdu`, `zah.pwd` | ⛔ безпека: дає змогу поїхати без ключа |

## Режими

`RSM` — один ідентифікатор на багато режимів; режим задає параметр `rsm`, команда
`start` / `stop`.

| `rsm` | Режим | Статус |
|---|---|---|
| `6` | Вартовий | ✅ |
| `4` | Комфорт під час паркування | 📋 T20 |
| `8` | Кемпінг | 📋 T20 |
| `80` | Вартовий у кемпінгу | ❔ |
| `1` | Комфорт салону | ❔ |
| `2` | Виявлення живих істот у салоні | ⛔ |
| `3` | Тривога одним натиском | ⛔ |
| `5` | Режим паркувальника (valet) | ⛔ |
| `7` | Дрифт | ⛔ |
| `9` | Сервісний режим | ⛔ |
| `10` | Фото з місця паркування | ❔ |
| `11` | Визначення місця авто | ⛔ позиція вже є в статусі |
| `20`, `23`, `90` | Обслуговування батареї, керування батареєю, розумна температура батареї | ❔ |
| `25` | Мегаватна зарядка | ⛔ не для 001 |
| `40` | Віддалений моніторинг | ⛔ відео вартового вже є окремою карткою |
| `41`, `42`, `43` | Віддалене переміщення авто та його авторизація | ⛔ безпека: авто рухається |
| `44` | «Здорова» зарядка | ❔ |
| `54` | Режим без слідів (не писати трек) | ⛔ |
| `70` | Світлове шоу / «танець» | ⛔ |
